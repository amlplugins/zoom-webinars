# @amlplugins/zoom-webinars

Native `@zoom/rest-api` SDK re-exported under the `@amlplugins` namespace.

> Zoom Webinars REST API — webinar creation, registrants, panelists, Q&A, recordings, branding.

## Install

```bash
npm install @amlplugins/zoom-webinars
```

## Use

```ts
import { /* named exports from @zoom/rest-api */ } from "@amlplugins/zoom-webinars";
// or
import sdk from "@amlplugins/zoom-webinars";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
